# LeadShelf стартовый пакет

LeadShelf - отдельный продукт для управления выкладкой, планограммами, оборудованием торгового зала, мобильным исполнением задач и аналитикой полки.

Этот пакет создан как старт для новой Codex-сессии. Он не является готовым кодовым проектом. Это набор решений, архитектуры, backlog и инструкций, чтобы новую разработку начать без смешивания с `leaddrive-v2`.

## Что читать первым

1. `docs/01-product-scope.md` - что строим и что намеренно не тащим из CRM.
2. `docs/02-architecture.md` - рекомендуемая архитектура приложения.
3. `docs/03-roadmap-backlog.md` - порядок реализации.
4. `docs/04-implementation-instructions.md` - правила для новой Codex-сессии.
5. `docs/05-decisions-risks.md` - с чем я согласен, с чем нет, и почему.
6. `docs/06-meeting-notes-from-leafio-demo.md` - выводы из демо Leafio/Shelf.
7. `docs/07-data-model-draft.md` - черновая модель данных.

## Главная идея

Не переносить весь MTM/CRM. Нужно вытащить только ядро:

- магазины / аптеки / форматы;
- оборудование и библиотека оборудования;
- план зала;
- планограммы;
- номенклатура, размеры, цены, остатки, продажи;
- задачи на торговую точку;
- мобильное подтверждение фото;
- отчеты и BI;
- AI/computer vision как отдельный слой, не как фундамент MVP.

## Что делать в новой сессии

Скопируй в новую сессию текст из `START_NEW_SESSION_PROMPT.md`.

Новая сессия должна сначала прочитать эти документы и только потом создавать кодовый проект.
