# LeadShelf

LeadShelf - отдельный продукт: field-force + shelf execution. Управление выкладкой, планограммами, оборудованием торгового зала, маршрутами/визитами, заказами, мобильным исполнением задач и аналитикой полки.

Репозиторий содержит планировочные документы (`docs/`) и monorepo с кодом (`apps/`, `packages/`, `services/`). Scope расширен до полного порта MTM-модуля - см. `docs/08-scope-expansion-mtm-full-port.md` и план миграции `docs/09-codex-migration-plan.md`.

## Запустить и показать

```bash
scripts/demo.sh up
```

Поднимает весь продукт с демо-данными на `http://localhost:8080` — этим его
показывают клиенту. Публичная ссылка, команды и путь до клиентского прода:
`docs/DEMO-STAND.md`.

## Главная идея

Не переносить весь MTM/CRM. Нужно вытащить только ядро:

- магазины / аптеки / форматы;
- оборудование и библиотека оборудования;
- план зала;
- планограммы;
- номенклатура, размеры, цены, остатки, продажи;
- задачи на торговую точку;
- мобильное подтверждение фото;
- отчеты и BI;
- AI/computer vision как отдельный слой, не как фундамент MVP.
