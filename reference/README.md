# Reference материалы

Эта папка содержит старые материалы из LeadDrive/MTM. Они нужны только как справка.

## Как использовать

Читать для понимания, но не копировать слепо.

Самые полезные:

- `legacy-leaddrive-docs/mtm-shelf-ai-golden-reference-architecture.md` - golden reference подход для AI compliance.
- `legacy-leaddrive-docs/mtm-shelf-detector-self-hosted-plan.md` - план self-hosted object detector.
- `legacy-leaddrive-docs/mtm-offline-sync-spec.md` - offline-first mobile sync.
- `legacy-leaddrive-docs/mtm-fmcg-gap-analysis.md` - что уже было в MTM и чего не хватало.
- `legacy-leaddrive-docs/mtm-sku-catalog-spec.md` - каталог SKU, цены, остатки.
- `legacy-leaddrive-docs/mtm-photo-watermark-spec.md` - фото-доказательство визита.
- `legacy-leaddrive-docs/mtm-equipment-inventory-spec.md` - оборудование.
- `legacy-leaddrive-docs/MTM_SPEC.md` - старая общая MTM спецификация.

## Важное предупреждение

LeadShelf не должен становиться полной копией MTM. Эти файлы помогут понять старые решения, но архитектура LeadShelf должна быть уже и чище:

- планограмма first;
- оборудование first;
- mobile execution first;
- analytics first;
- CRM/Sales/Marketing out.
