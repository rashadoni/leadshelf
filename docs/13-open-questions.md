    → Phase 6.
12. **Push-уведомления**: Expo Push (просто) vs свои FCM/APNs. → Phase 6/13.
13. **PDF/Excel экспорт**: библиотеки (exceljs, react-pdf/puppeteer).
    → Phase 7.
14. **Observability**: Sentry (web+mobile+API), структурные логи, uptime.
    → до пилота, минимум Sentry — в Phase 0 CI.
15. **Бэкапы**: Postgres (pg_dump расписание/WAL) и фото-бакет. Особенно

16. **Секреты прод-окружения**: env-менеджмент (SOPS/Doppler/вручную).
