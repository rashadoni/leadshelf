# LeadShelf: мобильный UX — «чтобы разобрался и 6-летний»

Обновлено: 2026-07-08.

Цель: полевое приложение (мерчендайзер в магазине, спешит, одна рука,
перчатки, плохой свет) должно быть предельно простым и приятным. Принцип:
**одна большая понятная кнопка на каждом экране** — приложение всегда без
слов отвечает «что нажать сейчас».

Контекст: приложение собрано как функциональный пилот; вся сила ушла в
логику (офлайн-синк, capture, корректность), UI остался каркасом
(сырой StyleSheet, без дизайн-системы). Самокритика подтверждена.

## P0 — быстрый скачок (код, без дизайнера)

1. **Фикс «Назад».** [сделано 2026-07-08] Камера/сканер/причина — оверлеи
   по состоянию; аппаратный «Назад» выкидывал весь экран задачи в список.
   Добавлен `BackHandler`: «Назад» закрывает оверлей, а не навигирует.
2. **Шаг-специфичный гид.** [сделано 2026-07-08] Раньше один силуэт на все
   шаги («сетка ради сетки»). Теперь: front/top_down — прямой силуэт,
   left/right depth — силуэт под углом (rotateY perspective) + стрелка,
   detail — прицел по центру.
3. **Прогресс «Шаг X/Y».** [сделано 2026-07-08] Видно в шапке камеры.
4. **Крупные кнопки + единая типографика/цвета/отступы.** [сделано
   2026-07-08] Кнопки 56–64px, единая палитра (stone/#1c1917) и радиусы
   применены к камере, экрану входа и списку задач.
5. **Плейн-язык** в подписях. [частично] Подписи над полями входа,
   счётчик «Сегодня», дружелюбные состояния; глубокая ревизия жаргона —
   позже.
6. **Экран «Готово!»** с большой галочкой + вибро. [сделано 2026-07-08]

## P1 — приятно

- Главный экран как большие карточки. [сделано 2026-07-08] Крупные
  карточки: название задачи, точка (📍), статус-точка, шеврон «открыть»,
  счётчик открытых задач.
- Микроанимации + haptics. [сделано] Тактильный отклик на кадр и «Готово»,
  pressed-состояния карточек/кнопок.
- Дружелюбные пустые/ошибки состояния. [частично] Пустой список = эмодзи +
  подсказка; sync-ошибки — позже.
- Авто-переход к следующему шагу. [не делаю: осознанно — резкое
  авто-открытие камеры мешает; заменено экраном «Готово» + галочками шагов.]

## P2 — на вырост

- **«Запомнить меня».** [сделано 2026-07-08] Организация и код сотрудника
  предзаполняются с прошлого входа.
- Онбординг первого запуска по одному пузырю-подсказке.
- QR/бейдж-логин.
- RN UI-библиотека + полная переверстка — крупная дизайн-инициатива,
  выигрывает от макета дизайнера; отдельно от этой сессии.

## Важно про доставку

Правки — в коде мобильного приложения. Чтобы увидеть на телефоне, APK
надо **пересобрать** (EAS preview, требует `eas login` владельца).
Веб-деплой на прод эти изменения не затрагивают.
